# Identity and private-file safety

Scoped extraction from `fix/release-audit`, based on the [immutable release audit](https://github.com/aaronroquefonseca/MyWhisper/blob/f018ab855af41759e275c80708d67973f2890587/docs/RELEASE_AUDIT.md). This is one layer of the three-PR stack; it does not close the complete R01–R51 audit. Base: `main`.

| Finding / grouped subissue | Root cause | Implemented correction | Regression coverage and executed validation | Migration / compatibility | Unresolved requirement |
| --- | --- | --- | --- | --- | --- |
| R06: concurrent first creation / legacy expansion | Unsynchronized create/read/write selected different signing or transport keys. | Cross-process lock, bounded private read, private fsynced atomic replacement and winning-key reread. | Concurrent creators/migrators and ten actual SIGKILL replacement cases, eight contenders each, then fresh-process verification of both fingerprints. | 32-byte signing seed and existing 64-byte identity preserved; updated binaries coordinate through device.key.lock. | Mixed old/new creators do not share the new lock; automatic orphan staging retirement and complete audit acceptance remain outside this slice. |
| R06/R40: malformed keys, permissions and temporary material | Existing corrupt/empty keys could be replaced or readable; initial writes were not private. | Preserve bad bytes as an error, enforce 0600 on the opened key descriptor and 0700 application directories; private staging from creation. | Malformed preservation, permissions, interrupted creation/migration, synthetic key fixtures only. | Existing application directories become private; malformed identities are never silently regenerated. | This does not encrypt the audio vault or establish physical power-loss recovery. |
| R12: identity display helper | Byte slicing an untrusted Unicode ID can panic. | Unicode-safe abbreviated display and canonical ID helper. | Unicode/malformed helper checks. | Valid hex identity display remains compatible. | Complete discovery/UI boundary validation remains on the integration branch. |
| R40/R50: identity and lock file-type safety | Following links or opening a FIFO can alter a foreign target or wait indefinitely. | O_NOFOLLOW/O_NONBLOCK and opened-descriptor regular-file checks. | FIFO no-writer, oversized-file and symlink checks; metadata preservation. | Reject special key/control files explicitly. | Database-file, backup and audio deletion semantics are not included. |
| R51: validation prerequisite | Main failed formatting and 88 lint diagnostics. | Separate mechanical preparation commit: equivalent branches/defaults/initializers, aliases, explicit non-truncating locks and speculative config argument grouping. | Strict formatting/Clippy, all existing assertions and five original ignores retained. | No settings/schema/key/protocol or worker-limit change. | This is not the whole release-gate implementation. |
| Native validation prerequisite | Two ordinary tests required host keyboards/uinput and failed in the Nix build. | Deterministic files/frames use the same production merge/dispatch code; a required native companion retains real startup, FD and exact Down/Up checks. | 83 portable tests and six native cases pass. Own virtual device is grabbed before any event; actual listener FD closes on Stop. | Test-only scan injection; production key/event behavior preserved. | Remaining hotkey/session fixes and physical microphone/compositor acceptance remain outside this slice. |

[Source checkpoint, executed checks and SHA-256 evidence manifest](validation.json). Tests use disposable identities, XDG directories, keys, databases and synthetic text. No project LICENSE was added, and no release/tag/merge/deployment was performed.
